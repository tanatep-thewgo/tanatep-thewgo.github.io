Senior project · flagship build

GestureTalk — Thai Sign Language Recognition

An app that recognizes Thai Sign Language in real time by tracking 21 hand landmarks and classifying the pose — 15 finger-spelled letters and 4 everyday words. Built twice: once as a Python desktop app, then ported to run entirely in the browser.

01 · Python desktop app

Real-time hand tracking with MediaPipe Hands, camera input via OpenCV, and a trained classifier over the 21 landmark points.

02 · Browser port

Rebuilt in vanilla JavaScript: camera access via getUserMedia(), client-side hand tracking with MediaPipe Tasks-Vision, and a hand-written inference engine so predictions run fully in-browser — no server involved.
